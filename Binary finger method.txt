	(3rd,1i)

1stIp: 192.168.129.1
LastIP: 192.168.129.254
Las/BR: 192.168.129.255

NOT:192.168.130.0

- Configure C1 as DHCP server
- Reserve the first 20 IPs
- Assign on VLAN 40
- Make sure P1 is a DHCP Client

--------------COMMAND--------------------

!@P1
conf t
int e0/0
no shut 
ip add dhcp
end
show ip int br


!@C1
conf t
vlan 40
 name ACCENTURE
 int vlan 40
 no shut

 ip dhcp excluded-address 192.168.129.1 192.168.129.20
 ip dhcp pool ACCENTURE
 network 192.168.129.0 255.255.255.0
 default-router 192.168.129.1
 domain-name ACCENTURE
 dns-server 10.61.1.0
 end
